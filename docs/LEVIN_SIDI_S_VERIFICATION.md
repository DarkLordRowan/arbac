# Levin–Sidi S — проверка формулы и атрибуции

## Что делает код

ID `levin_sidi_s` в Arbac сохраняется для совместимости с C++ и принятым
тезисом. Вычисляется факториальное преобразование:

\[
S_{k}^{(n)} = \frac{\Delta^k[(n+\beta)_{k-1}s_n/\omega_n]}{\Delta^k[(n+\beta)_{k-1}/\omega_n]}.
\]

При совпадении `omega`, `beta`, порядка, окна и способа обработки сингулярностей
это преобразование алгебраически совпадает с **реализованным факториальным
преобразованием Weniger-S**. Два идентификатора — не доказательство двух
независимых математических преобразований. Разные вычислительные пути могут
иметь разную численную устойчивость.

## Три уровня проверки

1. `test_levin_sidi_s_oracle.py`: 120 независимых расчётов точными
   рациональными дробями и проверка совпадения с Weniger при заданных параметрах.
2. `test_levin_sidi_s_factorial_kernel.py`: 25 тестов точного ядра;
   в рамках принятой модели метод должен возвращать известный предел.
3. `test_levin_sidi_s_mpmath_reference.py`: 135 проверок с **независимым
   рекуррентным вычислителем** mpmath `mp.levin(method="sidi", variant=...)`
   на трёх семействах, трёх оценках остатка, трёх beta и пяти порядках.
   Это сравнение нулевой стартовой строки, а не полное доказательство для всех
   произвольных сдвигов и особенностей округления.

**Статус:** численное соответствие с реализацией, называемой Sidi-S в mpmath,
подтверждено для конечного набора тестов. Историческое тождество с напечатанной
формулой из §19.3 Сиди необходимо подтвердить непосредственно по книге;
пока обозначение в библиографии `attribution_pending` сохраняется.

## Первоисточники

- A. Sidi, *Practical Extrapolation Methods: Theory and Applications* (2003),
  ch. 19, §19.3, pp. 363–374. DOI 10.1017/CBO9780511546815.021.
  https://doi.org/10.1017/CBO9780511546815.021
- E. J. Weniger, *Nonlinear Sequence Transformations for the Acceleration of
  Convergence and the Summation of Divergent Series*, arXiv:math/0306302.
  https://arxiv.org/abs/math/0306302
- mpmath documentation, `levin(method="sidi")`:
  https://mpmath.org/doc/current/calculus/sums_limits.html
- `mpmath.calculus.extrapolation.levin.factor_sidi` — открытая независимая
  рекуррентная реализация для сравнительной регрессии.

**Статья:** основной метод описывать его фактической формулой, а не объявлять
самостоятельно новым алгоритмом; специально указать связь с Weniger-S.
