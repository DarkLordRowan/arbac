# Второй этап переноса

В `Magister` обоих репозиториев добавлен следующий проверенный блок:
**19 рядов, 3 ускорителя и варианты остатков для Левина/Венигера**.
Всего в arbacc: **49 синтетических рядов и 9 ускорителей**.
Из исходных 109 C++-позиций перенесены 48; ещё один Python-ряд — базовый log1p.
Оставшаяся 61 позиция перечислена в таблице покрытия соседнего репозитория.

## Новые ряды

- Биномиальный `(1+x)^alpha` и производные геометрического ряда
  `m!/(1-x)^(m+1)` с проверкой больших m.
- `4*atan(x)`, `asin(x)-x`, `asin(2x)/2`, `2*asin(x/2)^2`.
- `cos(sqrt(x))`, `sin(x/sqrt(2))/sqrt(2)`, среднее sinh/sin и `2^x`.
- Логарифмический ряд `log((1+sqrt(1+x²))/2)` и вложенный квадратный корень.
- Интеграл Гаусса, `exp(x²)*erf(x)`, синус- и косинус-интегралы.
- Масштабированные ln(2), 2ln(2) и постоянная Эйлера.

Сохранены исходные id, индексы и нормировки. В частности, `erf` означает
**sqrt(pi)*erf(x)/2**, как в C++, а не нормированную функцию ошибок.
`ci_x` выдаёт сначала gamma, затем log(x), затем степенные члены.
У вложенного корня устранена съёмная особенность при x=0 рационализацией.

В Python константы pi, gamma и специальные функции вычисляются выбранным
backend с заданной точностью. Проверена независимость от глобальной точности
mpmath для 40 и 100 знаков. Использования double-констант в C++-оригиналах
пока ограничивают точность некоторых специальных рядов; это отражено в аудите.

## Ускорители

Добавлены `wynn_rho`, `brezinski_theta`, `drummond`.

У rho и theta параметр `order=k` означает чётный столбец 2k.
C++ использует непосредственно номер столбца 2k. На одном шаге при сдвиге n
rho требует n+2k+1 членов, theta — n+3k+1. Классический rho использует
узлы интерполяции x_n=n+1; эти узлы отличаются от членов обрабатываемого ряда.

У Левина, Венигера и Драммонда поддерживаются положительный `beta` и остатки:

| remainder | Оценка omega_n | Дополнительный доступ после a_(n+k) |
|---|---|---|
| `next` | a_(n+1) | 1 |
| `t` | a_n | 0 |
| `u` | (n+beta)*a_n | 0 |
| `v` | a_n*a_(n+1)/(a_(n+1)-a_n) | 1 |
| `v_shift` | a_(n+1)*a_(n+2)/(a_(n+2)-a_(n+1)) | 2 |

Глобальный знак omega не влияет на отношение взвешенных сумм; в C++ для
v_shift используется противоположный знак. Значение по умолчанию `next`
сохраняет поведение предыдущего этапа. При order=0 возвращается исходная
частичная сумма, дополнительные члены не запрашиваются.

Пример выбора плагинов:

```python
from arbacc.core import get
import arbacc.accelerators

rho = get("accelerators", "wynn_rho")({"order": 2})
theta = get("accelerators", "brezinski_theta")({"order": 2})
levin_u = get("accelerators", "levin")({
    "order": 4, "remainder": "u", "beta": "1.5",
})
```

Плагины используются через прежние runner и конфиги; отдельного режима запуска
не требуется. Расход данных зависит от выбранного остатка. Недоступная ячейка
или нулевой знаменатель дают доступную оценку меньшего порядка/исходную сумму;
такой fallback сам по себе не подтверждает сходимость.

## Исправления C++

- Восстановлен потерянный множитель в `half_asin_two_x`.
- Факториал и m+n в `m_fact_1mx_mp1_inverse` вычисляются после перехода
  из ограниченного типа индекса в тип значения.
- Исправлены числитель, сужение таблицы и расход данных классического rho.
- У u-остатка Драммонда задан beta=1, устраняющий деление на ноль при n=0.
- Проверка пустого ввода theta выполняется до чтения Sn[0].

## Проверки и воспроизведение

**1158 Python-тестов прошли**, в том числе на mpmath и Arb.
376 членов 47 рядов сопоставлены с настоящими C++-заголовками.
Дополнительно сопоставлены 42 значения новых ускорителей.
CTest проходит; запуск с AddressSanitizer/UndefinedBehaviorSanitizer также проверяется.
GUI-тесты не запускались. Команды запуска — в
[основной инструкции](mathematical-verification.md).

Независимые эталоны новых тестов:

- Закрытые формы и коэффициенты с точными биномиальными числами/факториалами.
- Для медленных рядов — конечные тождества через гармонические числа,
  а не требование получить десятки знаков простой суммой из 128 членов.
- Для rho — решение задачи рациональной интерполяции независимым линейным solver.
- Для theta — таблица на точных Fraction и опубликованная рекурсия.
- Для преобразований остатков — независимые конечные суммы с beta=1 и 2.5.
- В C++ прямой и рекурсивный Драммонд проверяются на пяти типах остатков.

Полная проверка остальных C++-вариантов и перенос оставшихся 61 позиций
продолжаются; статус sample_agrees численного пробника не означает независимой
сертификации формулы.
