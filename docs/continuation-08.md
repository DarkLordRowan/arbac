## Chang–Wynn

Сверено с [Chang et al. (2019), (3.18)–(3.20)](https://arxiv.org/pdf/1903.10198).
Вычисляется T_(2k)^(n). Для k>=1 нужны **2k+2** значения, для k=0 — одно.
Исправлены игнорирование order, подмена начала окна количеством членов,
выходы за заявленное окно и беззнаковое вычисление 1-k. Оценка берётся только
из чётного столбца. При вырождении ячейки становятся недоступными; возвращается
доступная оценка меньшего порядка или исходная точка. Это не доказательство
сходимости и не универсальное повышение точности.

Независимый рациональный эталон задаёт начальный T2 через сдвинутый v1 Левина,
а F1 — через определяющее четырёхточечное тождество, затем использует точную
рекурсию Fraction. Отдельно проверяются геометрическое ядро, нулевой порядок,
константы, расход данных, MPFR и комплексная арифметика ε-метода.

## Общая J-схема

Источник: [Homeier, (33), (94)](https://arxiv.org/pdf/math/0005209).
Прежний C++ использовал нулевую delta_S, пропускал последний уровень и имел
ошибочные обращения к an. Реализована общая схема обобщённых разностей
Delta/delta для числителя s_i/omega_i и знаменателя 1/omega_i.

C++ сохраняет первые два аргумента конструктора max_order и safeguard, добавляя
callback delta, вариант остатка и beta. Python предоставляет три явных выбора:
constant; pochhammer — 1/(z(z+1)); power — 1/z^delta_power, где
z=i+beta+delta_shift*level. beta>0, shift>=0, параметры конечны, предел порядка
проверяется. Все пять оценок остатка доступны. По умолчанию delta=1 и next-остаток
дают Drummond. При pochhammer и shift=p-1 результат совпадает с pJ.

**Изменение смысла safeguard:** это относительный порог сокращения знаменателя,
а не добавляемая к делителю константа. По умолчанию 1e-12; ноль отключает порог.
C++ отвергает неразрешённый знаменатель, Python оставляет доступную исходную
оценку. Ни один режим не гарантирует сходимость для произвольного ряда.

Проверки используют точный линейный функционал Fraction, независимую
оптимизированную pJ-схему, частный случай Drummond, разные начала, порядки,
остатки, параметры и некорректные входы. При сравнении с C++ Drummond учтено,
что его u-вариант имеет фиксированный beta=1.

## Адаптивный ε-алгоритм

Основа — [QUADPACK DQELG](https://www.netlib.org/quadpack/dqelg.f): сжатые диагонали,
выбор по эвристике локального изменения и ограничение таблицы в 50 ячеек.
Исправлены игнорирование изменившейся длины таблицы, нулевая начальная оценка,
использование ошибки вместо бесконечного элемента и недопустимость n=0.
Бесконечная вспомогательная ячейка представлена явно, без большого фиктивного числа.

**Наша политика продолжения:** после подтверждённой стагнации диагонали таблица
перезапускается с последней исходной точки. Пока новое окно наполняется,
сохраняется доступная оценка. Последующие исходные значения обрабатываются,
поэтому раннее плато не останавливает просмотр всей последовательности.
Это дополнение к ядру QELG, а не заявление о побитовом совпадении с QUADPACK.
Возвращаемая оценка не сопровождается сертифицированной границей ошибки.

Python: фиксированный порядок k, сдвигаемое окно из 2k+1 значений;
irregularity_threshold=1e-4, tolerance="auto" означает 10^(-dps).
C++ при tolerance=0 использует машинный epsilon числового типа; можно задать
положительный порог явно. Для межъязыковых сравнений он задан одинаково.

Независимый численный эталон — неизменённый исходник GSL QELG с небольшой
обёрткой, реализующей ту же политику перезапуска. GPL-исходник **не добавлен**
в репозиторий: optional-инструмент скачивает его в каталог сборки и проверяет
SHA-256 перед компиляцией. Проверены Python mpmath/Arb и C++ double на одинаковых
binary64-входах: знакопеременные суммы, геометрическая последовательность,
плато со сменой поведения, детерминированные псевдослучайные данные; длины
3, 7, 17, 61 и 121. Контролируются реальное сжатие, перезапуски и предел 50 ячеек.
