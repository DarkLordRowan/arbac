# Продолжение 9: сетка интерполяции Wynn rho

Добавлены grid_shift (конечное положительное число, по умолчанию 1) и
целочисленный grid_power >= 1 (по умолчанию 1): x_n=(n+shift)^power.
Числитель каждой ячейки — x_(n+column)-x_n; арифметика выполняется
в выбранном backend. Прежняя конфигурация сохраняет классическую сетку.

Первоисточник: [Weniger (1989)](https://arxiv.org/pdf/math/0306302),
(6.2-2), (6.2-9), (14.4-7). Реализован подслучай положительных целых степеней.
Это сеточное обобщение не тождественно параметризованным числителям
C++ generalized_type и gamma_rho_type; их аудит остаётся отдельной задачей.

Независимые тесты решают систему рациональной интерполяции степени (k,k),
сравнивают предел при бесконечном x с результатом rho. Проверены три сдвига,
три степени, четыре порядка, три последовательных окна, mpmath и Arb.
Дополнительно проверено точное ядро 7+3/x_n и отклонение неверных параметров.

Полный Python-набор без GUI: 3596 passed, 59 skipped, 6 предупреждений fork.
