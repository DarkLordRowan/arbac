# Продолжение: ещё три реализации ускорителей

Работа остаётся в локальных ветках `Magister`. Добавлены Python-ускорители
`levin_sidi_m`, `wynn_epsilon_fixed`, `iterated_aitken`; теперь их 14.
Все 109 источников каталога по-прежнему покрыты. Из 23 семейств C++ остаются 9.

## Исправления и смысл параметров

M-преобразование исправлено по Weniger (1989), формулам (9.2-5), (9.2-6), (9.4-1).
Используются падающие факториальные веса gamma+i, фиксированный порядок k
и окно s_n…s_(n+k). В C++ раньше роли n и k менялись внутри формулы, был лишний
множитель 1/(j+1), неправильное ограничение gamma и доступ к пустым векторам
до проверки размеров. Биномиальные коэффициенты теперь строятся в числовом типе,
без переполнения целого индекса. Поддержаны те же пять вариантов остатка.
Для u используется omega_i=(-gamma-i)*a_i. gamma конечен, положителен и >=k-1;
целые допустимы. Python по умолчанию использует next, C++ сохраняет прежний u;
при сравнении вариант нужно указывать явно.

В C++ `wynn_epsilon_2` теперь вычисляет epsilon_(2k)^(n) по стандартной рекурсии,
включая n=0. Исправлены выбор окна и зависимость результата от чётности n.
Непроверенные коррекции сингулярных ячеек удалены. Python `wynn_epsilon_fixed`
сдвигает начало окна на каждом шаге при фиксированном k; ранее существующий
`wynn_epsilon` увеличивает k при фиксированном начале.

Прежний `shanks_transform_alternating` содержал неверный первый шаг и зависимость
инициализации всех ячеек от одной s_n. Теперь это явно итерации процесса Эйткена.
Имя C++ сохранено для совместимости, Python использует `iterated_aitken`.
**Изменение смысла интерфейса C++:** n теперь начало окна для любого порядка;
k уровней требуют 2k+1 значений и how_much=n+2k+1. an больше не нужен.
Для математического преобразования Шенкса следует использовать `shanks`.
Отдельный тест показывает различие этих методов уже при k=2.

При вырождении C++ бросает исключение. Python использует доступную оценку
более низкого порядка или исходное значение; это продолжение расчёта, а не
доказательство сходимости. В epsilon fallback возвращаются только чётные столбцы.

## Проверки

- M: независимое решение точной рациональной системы для модельного остатка,
  5 вариантов остатка, gamma=4.5/7/100.5, порядки 1–4, начала 0/1/2/7.
- epsilon: независимое решение системы Шенкса, порядки 0–3 и разные начала.
- Итерации Эйткена: точная рекурсия Fraction, порядки 0–3 и разные начала.
- Сравнение 288 значений реального C++ с обоими Python backend, mpmath и Arb.
- Порядок 40 для M: геометрическое ядро в Python и MPFR 200 бит в C++.
- Доступ к данным, нулевой порядок, константные последовательности, некорректные
  параметры, пустые данные, сингулярности, согласованность рядов и последовательностей.

Основной C++ target `shanks` собран. CTest: 1/1. ASan/UBSan: без ошибок.
GUI-тесты исключены; предупреждения fork в существующих multiprocessing-тестах
сохранены. Коммиты и push не выполнялись.

Для воспроизведения используется команда из mathematical-verification.md.
Новая C++ выгрузка: `mathematical_regressions --fifth-algorithm-values`.

## Пример

```python
import arbacc.series, arbacc.accelerators
from arbacc.core import Context, AlgoState, get
from arbacc.precision import get_backend

ctx = Context(backend=get_backend('mpmath'), dps=80)
source = get('series', 'ln2')({'x': '1'}).build_stream(ctx)
algo = get('accelerators', 'levin_sidi_m')({
    'order': 4, 'gamma': '7', 'remainder': 'next',
})
state = algo.step(source, AlgoState(), ctx)
print(ctx.backend.to_str(state.estimate, ctx.dps))
```

Источники: [Weniger (1989), §§5, 9](https://arxiv.org/pdf/math/0306302),
[стандартная ε-рекурсия DLMF 3.9.11](https://dlmf.nist.gov/3.9.E11),
[Weniger (2000), различие Эйткена и Шенкса](https://arxiv.org/abs/math/0002111).
