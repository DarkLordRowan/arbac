# Проверка математики и перенос из shanks-university

Работа ведётся в `Magister` обоих репозиториев. В `arbac` создана локальная
ветка `Magister` от исходной `main`. Результаты зафиксированы локальными коммитами по запросу пользователя.
Отправка в remote не выполнялась.

## Что реализовано

В `arbacc` теперь 110 синтетических источников, файловый источник и 23 ускорителя.
Добавлено 106 источников: элементарные степенные ряды, биномиальные/каталановы,
подстановки x², x³, x⁴ и остаток ряда квадратного корня.
Имена из C++ сохранены там, где они существуют. Особенность старого каталога:
`x_div_1minx` означает x/sqrt(1-x), `x_div_1minx2` — x/sqrt(1-x²).

Добавлены `shanks` (определители), `richardson` (ошибка на сетке с отношением 1/4),
`levin` и `weniger`. Их значения по умолчанию сохраняют форму DLMF с оценкой
остатка следующим членом и beta=1. Во втором этапе добавлены `wynn_rho`,
`brezinski_theta`, `drummond`; у Левина, Венигера и Драммонда поддерживаются
`next`, `t`, `u`, `v`, `v_shift` и произвольный положительный beta.
В третьем этапе исправлены и проверены прямые/рекурсивные формы C++ Левина и Sidi-S.
Sidi-S соответствует факториальному S-преобразованию Python `weniger`.
Добавлены процессы `overholt` и `lubkin_w`.
`order` у этих методов задаёт фиксированный порядок; окно сдвигается по мере итераций.
У `wynn_epsilon` порядок растёт: шаг k использует 2k+1 частичных сумм.

Исправления:

- Винн использовал половину заявленных членов; теперь таблица действительно
  доходит до epsilon_(2k)^(0). Недоступные ячейки распространяются без операций с None.
- Сумма геометрического ряда выдаётся только при |q|<1, ряда Дирихле для zeta — при s>1.
  Значение аналитического продолжения больше не подменяет сумму расходящегося ряда.
- Новые ряды проверяют область сходимости и конечность аргумента.
- Для atan/asin и проверки конечности добавлены операции обоих backend.
- В requirements добавлен pyarrow, необходимый существующему Parquet-хранилищу и тестам.

При сингулярной таблице ускоритель возвращает доступную оценку или исходную
частичную сумму. Это стратегия продолжения вычисления, а не признак сходимости.
Для Arb интервал, содержащий ноль, нельзя считать доказанным точным нулём.

## Независимые проверки

`tests/test_mathematical_oracles.py` контролирует покрытие реестра; независимые
проверки рядов и ускорителей распределены по `tests/test_*`. Эталоны: точные рациональные коэффициенты, независимый контекст mpmath,
закрытые формы, определители Ханкеля, геометрическое ядро, сумма двух экспонент,
константные последовательности и вырожденные случаи. Проверены mpmath и Arb.
Для 97 рядов сравниваются первые 8 членов с настоящими C++-заголовками: 776 сравнений.
Дополнительно сравниваются 315 значений ускорителей для разных окон,
порядков и оценок остатка; прямой и рекурсивный Драммонд сопоставляются в C++.
Добавление нового плагина без математического эталона ломает проверку полноты покрытия.
Проверка конечного числа членов не доказывает сходимость для любых аргументов.

Запуск из Linux/WSL, после сборки C++ по инструкции соседнего репозитория:

```sh
cd arbac
python -m pip install -r requirements.txt
# Необязательный второй backend для независимых проверок:
python -m pip install python-flint
SHANKS_CPP_REGRESSIONS=/tmp/shanks-build/mathematical_regressions \
SHANKS_CPP_CATALOGUE=/tmp/shanks-build/catalogue_probe \
  python -m pytest --ignore=tests/gui
```

Проверенный запуск: Python 3.13, mpmath 1.4.1, python-flint 0.9.0;
3565 тестов прошли. GUI-тесты не запускались. Шесть предупреждений относятся к
существующему использованию fork в многопоточном процессе.
Если переменная SHANKS_CPP_REGRESSIONS не задана, межъязыковая проверка явно пропускается.

## Функциональность из TypeScript

`arbacc.convergence.analyze_convergence` переносит диагностику из
`AlgorithmSeriesConvergenceTable/model/convergenceUtils.ts` в shanks-university:
односторонность, изменения знака, монотонность ошибки, номера нарушений,
допуски на число нарушений и предпочтение сохранённого deviation.
Поддерживаются вещественные и комплексные точки {re, im}.

Числа обрабатываются backend с заданной точностью. Дефолтный абсолютный допуск — 0,
его можно задать строкой. Это отличается от фиксированного 1e-15 в браузере и
позволяет различать ошибки порядка 1e-100. Для прежнего поведения задайте
`tolerance="1e-15"`. Конечная траектория характеризуется, но её сходимость не доказывается.

```python
from arbacc.core import Context
from arbacc.precision import get_backend
from arbacc.convergence import analyze_convergence

ctx = Context(backend=get_backend("mpmath"), dps=100)
report = analyze_convergence([
    {"n": 0, "deviation": "-1e-70"},
    {"n": 1, "deviation": "1e-80"},
], None, ctx)
assert report["side"] == "two_sided"
assert report["monotonicity"] == "strict_decreasing_error"
```

Матрицы, рейтинги, экспорт и интерфейс из TypeScript целиком ещё не перенесены.
Все основные семейства C++ имеют Python-аналоги; дополнительные варианты остаются задачей:
см. `shanks-university/docs/catalogue-coverage.md` и `mathematical-audit.md`.
