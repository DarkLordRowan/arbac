# Пропущенные тесты: диагностический план

Последняя пользовательская Windows-проверка ядра: 4013 passed, 61 skipped;
Research: 35 passed. Пропуски **не эквивалентны** прохождению проверки.

В исходниках причины skip сгруппированы по:

- backend `arb`/`python-flint` отсутствует или неподдерживаемый режим округления;
- нет внешних C++-бинарников для сравнения (`SHANKS_CPP_REGRESSIONS`,
  `SHANKS_CPP_CATALOGUE`);
- отсутствует собранный независимый GSL QELG эталон (`SHANKS_QELG_REFERENCE`);
- другие условные пропуски, требующие отдельного изучения.

Получите **точные** причины на Windows:

```powershell
python -m pytest tests research_tests -q -rs --tb=short *> out\full_tests_with_skips.txt
Get-Content out\full_tests_with_skips.txt -Tail 120
```

Для строгого «все тесты прошли» нужны либо доступные эталоны и окружение,
либо чётко задокументированное объяснение каждого отсутствующего внешнего условия.
Нельзя считать skip успешным сравнением C++ или GSL.

Для предметной статьи обязательны также повторные независимые проверки
результатов больших Stage C/E JSON-прогонов и сохранение идентификаторов
конфигураций и версий кода.
