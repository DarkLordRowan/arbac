# examples — примеры конфигов и данных

Здесь примеры конфигов для разных сценариев и тестовые данные
для `from_file`.

## Файлы

- **config_minimal.json** — минимальный конфиг: одна серия, один шум,
  один акселератор, без постобработок. Для быстрой проверки CLI.
- **config_full.json** — полный конфиг: развёртка dps, два ряда,
  шум со scope, два акселератора со scope, глобальная постобработка,
  глобальная огибающая. Демонстрирует все фичи.
- **data/sample_series.csv** — тестовые числа в CSV (UTF-8 with BOM).
- **data/sample_series.txt** — те же числа в TXT.

Полное описание — в корневом README.md. Здесь — краткие правила.
